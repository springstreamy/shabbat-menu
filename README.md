# תפריט שבת

אפליקציה לתכנון תפריט לשבת ולחג עם המשפחה והחברים. הנתונים (קבוצות, מנות וצ'אט) נשמרים ב-[Supabase](https://supabase.com), והאתר עצמו הוא קבצים סטטיים שאפשר להעלות ל-GitHub Pages.

## איך זה עובד
- אין הרשמה ואין סיסמה. כל דפדפן נכנס אוטומטית כמשתמש אנונימי.
- כל קבוצה מקבלת קוד בן 4 ספרות. מצטרפים עם הקוד ובוחרים שם.
- בטלפון חדש (או אחרי ניקוי הדפדפן) מצטרפים שוב עם הקוד ובוחרים את השם שלכם ברשימה. המנות והמשימות שלכם חוזרות.
- אחרי 3 ניסיונות עם קוד שגוי בשעה, הקבוצה ננעלת להצטרפות עד שתעבור שעה. כך ניחוש של הקוד לוקח חודשים.

## הגדרת Supabase (פעם אחת)
1. **מסד הנתונים:** ב-**SQL Editor** מדביקים את כל התוכן של `supabase.sql` ולוחצים **Run**.
2. **כניסה אנונימית:** **Authentication > Sign In / Providers**, מפעילים **Allow anonymous sign-ins** ושומרים.
3. **חיבור האתר:** ב-`config.js` מדביקים את ה-**Project URL** ואת ה-**Publishable key** (או anon key). מוצאים אותם בכפתור **Connect** או ב-**Project Settings > API Keys**. אין בעיה שהם גלויים, כי ההגנה על הנתונים היא בהרשאות שב-`supabase.sql`. **לא** להדביק את ה-secret / service_role key.

## התקנה כאפליקציה
- **אנדרואיד / כרום במחשב:** במסך הבית של האתר מופיע כפתור **התקנה**.
- **אייפון:** פותחים בספארי, כפתור השיתוף ואז **הוספה למסך הבית**.

## מה מוגן
- רק מי שהצטרף לקבוצה (עם הקוד) רואה את התפריטים, המנות, הצ'אט והאנשים שלה.
- שמות הקבוצות גלויים לכל מי שנכנס לאתר, כדי שאפשר יהיה לבחור קבוצה להצטרף אליה.
- כל חבר בקבוצה רואה את הקוד שלה, כדי שיוכל לשלוח אותו לאחרים. רק מי שפתח את הקבוצה יכול לשנות את הקוד או למחוק את הקבוצה.
- מי שיודע את הקוד יכול לבחור כל שם ברשימה. זה מתאים למשפחה, לא לקבוצה של זרים.

## חשוב לדעת
בתוכנית החינמית, פרויקט שלא השתמשו בו שבוע עובר להשהיה. אם האפליקציה מפסיקה לעבוד אחרי הפסקה ארוכה, נכנסים ל-Supabase ולוחצים **Restore project**. הנתונים לא נמחקים.
